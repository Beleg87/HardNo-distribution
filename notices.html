## Compatibility boundary

[GPLv3 Section 13](https://www.gnu.org/licenses/gpl.en.html) and
[AGPLv3 Section 13](https://www.gnu.org/licenses/agpl-3.0.html) permit combining
separate GPLv3 and AGPLv3 components while preserving the terms on each part.
This does not convert upstream GPL code to AGPL or eliminate Corresponding Source
requirements. The declared MIT/BSD/Apache-2.0/BlueOak licenses are retained;
alternative permissive grants are used where offered (MIT for WTFPL-or-MIT and
MIT-or-CC0). No incompatible standard npm license was identified in this
inventory; that assessment is not a legal certification. Custom-licensed Nordic data is excluded from this release. A list-selection
marker retires older mixed filter caches without changing login/provider settings.

## Distribution and AGPL Section 13

HN! runs locally as a Chrome extension, with no hosted HN! application/backend.
Provider downloads and the Web Store upload client contact external services;
they do not provide a network-operated HN! service to remote users.
`tests/serve-fixtures.js` binds only to 127.0.0.1 as a development fixture.
There is no deployed remote source-offer endpoint to verify, and this change does
not claim Section 13 compliance for a future hosted deployment. If a modified
version is offered for remote interaction, supply and verify a prominent, free
Corresponding Source offer for that actual version, including combined code.

The complete source package includes HN!'s editable source, scripts, exact filter
build inputs, all 76 locked npm archives and 11 immutable preferred-form upstream
source revisions, preserving their licenses. See [source inventory and offline
rebuild instructions](third_party/README.md). The release extracts the actual
source ZIP into a fresh directory, refuses missing/corrupt archives, then repairs
the test copy and rebuilds offline with every runtime byte compared to the release.
This verifies the delivered package, rather than treating a lockfile or homepage
as a substitute for source.

When distributing a runtime release, distribute its matching
`hardno-source-VERSION.zip` with accessible copying facilities. A future Web Store
listing must link the matching source; no publication or invented public URL is
performed by this local build. Existing historical ZIPs and grants remain intact.

`npm run check:licenses` and `npm run check:source` verify original-code headers,
metadata, artwork terms, retained upstream licenses and the complete source
inventory. `tools/qualify-source.py` verifies the extracted package and offline
build. These checks do not claim to certify a future hosted service or unknown
future changes to upstream licenses.
